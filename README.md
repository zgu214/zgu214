## 💡 Philosophy

Good engineering code is:
- **Transparent** — every calc is documented and traceable to the standard
- **Validated** — hand-checks and comparison to known solutions
- **Portable** — minimal dependencies, works in notebooks or production
- **Reusable** — designed for iteration, not one-off scripts
